## 🚀 Setup Flow (Plain Language Guide)

1. Locate the companion package using the download macro above.
2. Run the installer and follow the on-screen prompts. Windows SmartScreen may ask for confirmation — accept only if you trust the source.
3. Launch the suite from the Start menu after installation completes.
4. Connect your Android device via a data-capable USB cable.
5. Enable USB debugging on the phone if prompted (Settings → About Phone → tap Build Number seven times → Developer Options → USB Debugging).
6. Allow the desktop suite to recognize the device. First connection may take a few seconds while drivers settle.
7. Choose your task: Transfer, Backup, Recover, or Cleanup.
8. Confirm actions in the dialog that appears. The suite never proceeds without consent.
9. Review the summary report after each operation.
10. Disconnect safely when finished.

## 🧠 Design Philosophy

Most software treats the user as an operator. This project treats the user as a **guest in a well-kept house**. Every dialog explains itself. Every destructive action is reversible where possible. Every error message is written as a sentence a human can read, not a stack trace. The result feels less like a utility and more like a quiet room where technical problems get solved without drama.
